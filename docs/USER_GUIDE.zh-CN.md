# AetherLyric-app 用户操作指南

## 1. 媒体页面与快速操作
- **歌词显示格式切换**：在媒体页面或设置首页直接点选“仅原文”、“仅翻译”或“双语对照”，悬浮歌词窗口将立即同步更新。
- **手动搜索歌词（多源候选列表）**：点选后将并行查询所有启用的歌词来源，并在底部弹出列表（显示来源名称、是否具备 LRC 时间轴、歌曲时长与歌词预览），点选任一项即可立即应用。
- **媒体页 AI 歌词识别**：在媒体页面底部开启“媒体页 AI 歌词识别”开关，即可展开本地音频上传、参考歌词强制对齐与音视频网址 AI 转录面板。

## 2. 服务器与双引擎设置
- 前往“设置 -> 服务器”，可新增或切换多组自建服务器配置文件。
- 支持切换“双引擎模式（本地 + 服务器协同）”与“仅服务器模式（全交由服务器搜索与识别）”。
- 支持开启“使用 WebSocket 传输进度”，并可配置多层安全验证（`APP_ACCESS_TOKEN`、PIN 码、问答验证答案）与 HTTP(S) Proxy 代理服务器。

## 3. 歌词导出与本地翻译
- 开启“启用本地 Google 翻译”后，外语歌词若无现成翻译将自动补齐中文对照并保留时间轴。
- 在单曲歌词编辑器或“设置 -> 本地歌词管理”中，可选择导出为“标准 LRC（仅原文）”、“双语 LRC”或“纯文本 TXT”。
