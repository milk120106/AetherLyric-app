# AetherLyric-app 使用者操作指南

## 1. 媒體頁面與快速操作
- **歌詞顯示格式切換**：於媒體頁面或設定首頁直接點選「僅原文」、「僅翻譯」或「雙語對照」，懸浮歌詞視窗將立即同步更新。
- **手動搜尋歌詞（多源候選清單）**：點選後將平行查詢所有啟用的歌詞來源，並於底部彈出清單（顯示來源名稱、是否具備 LRC 時間軸、歌曲時長與歌詞預覽），點選任一項即可立即套用。
- **媒體頁 AI 歌詞辨識**：於媒體頁面底部開啟「媒體頁 AI 歌詞辨識」開關，即可展開本機音訊上傳、參考歌詞強制對齊與影音網址 AI 轉錄面板。

## 2. 伺服器與雙引擎設定
- 前往「設定 -> 伺服器」，可新增或切換多組自架伺服器設定檔。
- 支援切換「雙引擎模式（本地 + 伺服器協同）」與「僅伺服器模式（全交由伺服器搜尋與辨識）」。
- 支援開啟「使用 WebSocket 傳輸進度」，並可配置多層安全驗證（`APP_ACCESS_TOKEN`、PIN 碼、問答驗證答案）與 HTTP(S) Proxy 代理伺服器。

## 3. 歌詞匯出與本地翻譯
- 開啟「啟用本地 Google 翻譯」後，外語歌詞若無現成翻譯將自動補齊繁體中文對照並保留時間軸。
- 於單曲歌詞編輯器或「設定 -> 本地歌詞管理」中，可選擇匯出為「標準 LRC（僅原文）」、「雙語 LRC」或「純文字 TXT」。
